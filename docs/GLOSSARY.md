# 📚 Glossary

Daftar istilah dan definisi untuk DC-09 Capstone Project Management System.

---

## A

**API** - Application Programming Interface. Interface untuk komunikasi antar aplikasi.

**Authentication** - Proses verifikasi identitas pengguna (login).

**Authorization** - Proses penentuan apa yang boleh dilakukan pengguna setelah login.

**Axios** - HTTP client library untuk membuat request ke API.

---

## B

**Backend** - Server-side application yang menangani logika bisnis dan database.

**Bcrypt** - Library untuk hashing password secara aman.

**Bearer Token** - Token yang dikirim di header Authorization untuk autentikasi.

**Bundle** - Kumpulan file JavaScript yang sudah di-compile dan di-minify.

---

## C

**Capstone Group** - Tim mahasiswa yang mengerjakan capstone project.

**CORS** - Cross-Origin Resource Sharing. Mekanisme untuk akses resource dari domain berbeda.

**CSV** - Comma-Separated Values. Format file untuk data tabel.

**Cloudinary** - Cloud storage service untuk menyimpan file.

---

## D

**Database** - Sistem penyimpanan data terstruktur.

**Dashboard** - Halaman utama yang menampilkan informasi ringkas.

**Deployment** - Proses menjalankan aplikasi di production environment.

**Document** - File panduan atau referensi untuk capstone project.

---

## E

**Endpoint** - URL spesifik di API yang dapat diakses.

**Environment Variable** - Variabel konfigurasi yang disimpan di file .env.

**Express.js** - Web framework untuk Node.js.

---

## F

**Feature** - Fitur atau fungsi dalam aplikasi.

**Frontend** - Client-side application yang ditampilkan di browser.

**Framework** - Struktur dan tools untuk membangun aplikasi.

---

## G

**Git** - Version control system untuk tracking perubahan code.

**GitHub** - Platform hosting untuk repository Git.

**Google OAuth** - Sistem login menggunakan akun Google.

---

## H

**Hash** - Fungsi untuk mengubah data menjadi string unik (one-way).

**Health Check** - Endpoint untuk mengecek status API.

**Helmet.js** - Middleware untuk menambah security headers.

---

## I

**Invitation** - Undangan untuk bergabung dengan tim capstone.

**Index** - Struktur database untuk mempercepat query.

**Integration Test** - Test yang menguji multiple components bersama.

---

## J

**JWT** - JSON Web Token. Token untuk autentikasi stateless.

**Joi** - Library untuk validasi schema data.

---

## L

**Learning Path** - Jalur pembelajaran (Front-End, Back-End, dll).

**Learning Group** - Kelompok mahasiswa dalam satu learning path.

**Localhost** - Alamat lokal untuk development (127.0.0.1).

---

## M

**Middleware** - Function yang dijalankan sebelum route handler.

**MongoDB** - NoSQL database yang menyimpan data dalam format JSON.

**Mongoose** - ODM (Object Data Modeling) library untuk MongoDB.

**Multer** - Middleware untuk handling file upload.

---

## N

**Node.js** - JavaScript runtime untuk server-side development.

**Nodemailer** - Library untuk mengirim email.

**npm** - Node Package Manager. Package manager untuk Node.js.

---

## O

**OAuth** - Open standard untuk autentikasi dan autorisasi.

**ODM** - Object Data Modeling. Library untuk memetakan object ke database.

---

## P

**Passport.js** - Middleware untuk autentikasi di Express.

**Pinia** - State management library untuk Vue.js.

**Production** - Environment untuk aplikasi yang sudah live.

---

## Q

**Query** - Permintaan data dari database.

---

## R

**RBAC** - Role-Based Access Control. Sistem otorisasi berdasarkan role.

**REST** - Representational State Transfer. Arsitektur API yang menggunakan HTTP methods.

**Route** - URL path yang dapat diakses di aplikasi.

**Router** - Komponen untuk menangani routing di aplikasi.

---

## S

**Schema** - Struktur dan aturan data di database.

**Scope** - Bagian dari aplikasi yang dimodifikasi (dalam commit message).

**Service** - Layer yang berisi business logic.

**SMTP** - Simple Mail Transfer Protocol. Protocol untuk mengirim email.

**State Management** - Sistem untuk mengelola state aplikasi.

**Swagger** - Tool untuk dokumentasi API.

---

## T

**Team ID** - Identitas unik untuk setiap capstone team.

**Timeline** - Daftar milestone dan deadline capstone project.

**Token** - String yang merepresentasikan session atau autentikasi.

**Type** - Jenis commit (feat, fix, docs, dll).

---

## U

**Unit Test** - Test yang menguji individual function/component.

**Use Case** - Skenario penggunaan atau fitur spesifik.

**User** - Pengguna aplikasi (mahasiswa, admin, mentor).

---

## V

**Validation** - Proses pengecekan data sesuai aturan.

**Vercel** - Platform untuk deploy frontend aplikasi.

**Vue.js** - Progressive JavaScript framework untuk frontend.

**Vite** - Build tool modern untuk frontend development.

---

## W

**Webhook** - URL yang menerima request dari service eksternal.

**Worksheet** - Fitur untuk team check-in (Phase 2).

---

## X

**XSS** - Cross-Site Scripting. Vulnerability untuk inject script ke halaman.

---

## Z

**Zip** - Format file untuk kompresi.

---
