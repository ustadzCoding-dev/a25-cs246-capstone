## 🚀 Getting Started

### First Time Login

1. **Go to the application:** `http://localhost:5173`
2. **Click "Sign Up"** if you don't have an account
3. **Fill in your details:**
   - Name
   - Email
   - Password (min 6 characters)
   - Learning Path (select from dropdown)
   - University
4. **Click "Register"**
5. **Login with your credentials**

### Login Options

**Option 1: Email & Password**

- Click "Login"
- Enter email and password
- Click "Sign In"

**Option 2: Google Account**

- Click "Login with Google"
- Authorize the application
- Complete your profile (if new user)

## 🔐 Authentication

### Register New Account

```

```

## 👥 Team Management

### Create a Team

**Step 1: Go to Tim Saya**

```
1. Click "Tim Saya" in sidebar
2. Click "Buat Tim Baru" button
```

**Step 2: Fill Team Information**

```
1. Team Name: Enter your team name
2. Select Use Case: Choose from available use cases
   - Each use case has specific team size and composition
3. Form will auto-generate member input fields
```

**Step 3: Add Team Members**

```
1. For each member field:
   - Enter member's Student ID (e.g., fui0001)
   - Learning path will auto-populate
2. Verify all members are correct
3. Verify composition matches requirements
```

**Step 4: Submit**

```
1. Click "Daftar Tim"
2. Wait for confirmation
3. You'll see "Team registered successfully"
```

### Edit Team

**Only if team status is "Pending":**

```
1. Go to Tim Saya
2. Click "Edit" button on your team
3. Modal opens showing current members
4. You can:
   - Add new members
   - Remove existing members
   - Change member order
5. Verify composition is still valid
6. Click "Save Changes"
7. Invitations will be sent to new members
```

### View Team Details

```
1. Go to Tim Saya
2. Click on team name or "View Details"
3. You'll see:
   - Team name
   - Team members
   - Use case information
   - Team status
   - Creation date
```

```

2. Click filter button
3. Select type:
   - Milestones
   - Deadlines
   - Events
   - All

```

### Check Deadlines

```
1. Go to Timeline page
2. Look for "Overdue" or "Upcoming" badges
3. Red badge = Overdue
4. Yellow badge = Upcoming (within 7 days)
```

## 📋 Worksheet Submission

### View Worksheet Periods

```
1. Click "Worksheet" in sidebar
2. You'll see all worksheet periods
3. Each period shows:
   - Period number
   - Title
   - Start date
   - End date
   - Status (Draft, Active, Closed, Validated)
```

### Submit Worksheet

**Step 1: Select Period**

```
1. Go to Worksheet page
2. Find the active period
3. Click "Submit Worksheet"
```

**Step 2: Fill Worksheet**

```
1. Write description of your activities
   - Minimum 50 characters
   - Be detailed and specific
2. Upload evidence files:
   - Screenshots
   - Documents
   - Maximum 5 files
   - Maximum 5MB per file
3. Click "Save as Draft" to save without submitting
```

**Step 3: Submit**

```
1. Click "Submit Worksheet"
2. Confirm submission
3. You'll see "Worksheet submitted successfully"
4. Status changes to "Submitted"
```

### View Submission Status

```
1. Go to Worksheet page
2. Find your submission
3. Status shows:
   - Draft: Not yet submitted
   - Submitted: Waiting for validation
   - Completed: Validated and approved
   - Incomplete: Rejected or not submitted
```

### View Admin Feedback

```
1. Go to Worksheet page
2. Find your submission
3. Click "View Details"
4. You'll see:
   - Your submission
   - Admin validation notes
   - Validation status
```

## ❓ FAQ

### Q: How do I create a team?

**A:** Go to Tim Saya → Click "Buat Tim Baru" → Fill form → Submit

### Q: Can I edit my team after creating it?

**A:** Yes, if team status is "Pending". Click "Edit" button on your team.

### Q: What if I'm invited to a team?

**A:** Go to Tim Saya → Look for pending invitations → Click "Accept" or "Reject"

### Q: How do I download documents?

**A:** Go to Dokumen → Find document → Click "Download"

### Q: When is the team registration deadline?

**A:** Check the Timeline page for the deadline.

### Q: How do I submit a worksheet?

**A:** Go to Worksheet → Select active period → Fill form → Click "Submit"

### Q: Can I edit my profile picture?

**A:** Yes, go to Profile → Click "Choose Photo" → Select new image

### Q: What if I forget my password?

**A:** Contact admin or use "Forgot Password" link on login page

### Q: Can I change my learning path?

**A:** Contact admin to change learning path

### Q: How do I logout?

**A:** Click profile icon (top right) → Click "Logout"

## 🆘 Troubleshooting

### Can't login

- Check email and password are correct
- Try "Login with Google" if available
- Clear browser cache and try again

### Team creation fails

- Check all members are valid student IDs
- Verify team composition matches use case requirements
- Check all required fields are filled

### Can't upload profile picture

- Check file size (max 5MB)
- Check file type (JPEG, PNG, GIF, WebP)
- Try different browser

### Worksheet won't submit

- Check description is at least 50 characters
- Check files are under 5MB each
- Check maximum 5 files

### Can't download document

- Check internet connection
- Try different browser
- Contact admin if problem persists
