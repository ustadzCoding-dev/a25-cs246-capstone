## 📊 Dashboard

### View Dashboard

```
1. Login as admin
2. You'll see Admin Dashboard
3. Dashboard shows:
   - Total teams
   - Pending teams
   - Approved teams
   - Total students
   - Total documents
```

### Key Metrics

- **Total Teams:** All teams in system
- **Pending Teams:** Teams awaiting approval
- **Approved Teams:** Teams that passed validation
- **Total Students:** All registered students
- **Total Documents:** All uploaded documents

## 👥 Team Management

### View All Teams

```
1. Click "Kelola Tim" in sidebar
2. You'll see all teams
3. Filter by status:
   - Pending (awaiting approval)
   - Approved (accepted)
   - Rejected (declined)
```

### Approve Team

```
1. Go to Team Management
2. Find team with "Pending" status
3. Click "Approve" button
4. Confirm approval
5. Team status changes to "Approved"
6. Team leader is notified
```

### Reject Team

```
1. Go to Team Management
2. Find team to reject
3. Click "Reject" button
4. Enter rejection reason
5. Click "Confirm"
6. Team status changes to "Rejected"
7. Team leader is notified
```

### View Team Details

```
1. Go to Team Management
2. Click team name
3. You'll see:
   - Team members
   - Use case
   - Composition
   - Creation date
   - Status
```

### Delete Document

```
1. Go to Document Management
```

## 📋 Worksheet Validation

### Create Worksheet Period

```
1. Click "Kelola Worksheet"
2. Click "Create Period"
3. Fill form:
   - Period Number: 1, 2, 3, etc.
   - Title: Period title
   - Start Date: When period starts
   - End Date: Submission deadline
   - Auto Validation Date: When auto-validation runs
4. Click "Create"
```

### Activate Period

```
1. Go to Worksheet Management
2. Find period with "Draft" status
3. Click "Activate" button
4. Period status changes to "Active"
5. Students can now submit worksheets
```

### View Submissions

```
1. Go to Worksheet Management
2. Select a period
3. You'll see all submissions
4. Filter by status:
   - Draft
   - Submitted
   - Completed
   - Incomplete
```

### Validate Worksheet

```
1. Go to Worksheet Management
2. Select period
3. Find submission to validate
4. Click "Validate"
5. Set status:
   - Completed: Approved
   - Incomplete: Rejected
6. Add validation notes
7. Click "Save"
```

## 🆘 Troubleshooting

### Can't approve team

- Check team composition is valid
- Verify all members are registered
- Try refreshing page

### Worksheet validation fails

- Check submission has all required fields
- Verify files are uploaded
- Try again later

### Can't upload document

- Check file size (max 50MB)
- Check file type is allowed
- Try different browser
