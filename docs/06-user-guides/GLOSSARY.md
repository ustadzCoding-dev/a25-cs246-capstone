# 📖 GLOSSARY

Terms and definitions used in the system.

---

## A

**API** - Application Programming Interface. Interface for software to communicate.

**Authentication** - Process of verifying user identity using credentials.

**Authorization** - Process of determining what authenticated user can access.

---

## B

**Backend** - Server-side application logic and database.

**Backup** - Copy of data for recovery purposes.

**Bcrypt** - Password hashing algorithm for secure storage.

---

## C

**Capstone** - Final project for academic program.

**CORS** - Cross-Origin Resource Sharing. Allows requests from different domains.

**Cloudinary** - Cloud service for image storage and delivery.

---

## D

**Database** - Organized collection of data.

**Deployment** - Process of moving code to production environment.

**DicodingId** - Unique identifier for each student.

---

## E

**E2E Testing** - End-to-End testing of complete user workflows.

**Environment Variables** - Configuration values stored outside code.

**ESLint** - Tool for identifying code style issues.

---

## F

**Frontend** - Client-side user interface.

**Full Stack** - Both frontend and backend development.

---

## G

**Git** - Version control system for code management.

**GitHub** - Platform for hosting Git repositories.

**Google OAuth** - Authentication using Google account.

---

## H

**Hash** - One-way encryption of passwords.

**HTTPS** - Secure version of HTTP protocol.

---

## I

**Integration Testing** - Testing of component interactions.

**Invitation** - Request to join a team.

---

## J

**JWT** - JSON Web Token. Token-based authentication.

---

## L

**Learning Path** - Student specialization area.

**Localhost** - Local development server (127.0.0.1).

---

## M

**Middleware** - Software that processes requests/responses.

**MongoDB** - NoSQL database system.

**Mongoose** - ODM for MongoDB in Node.js.

---

## N

**Nodemailer** - Email sending library for Node.js.

**Node.js** - JavaScript runtime for server-side development.

---

## O

**OAuth** - Open standard for authentication.

---

## P

**Pinia** - State management library for Vue.js.

**Postman** - API testing tool.

---

## R

**REST** - Representational State Transfer. API design pattern.

**Route** - URL endpoint in application.

---

## S

**Schema** - Structure definition for database collections.

**Staging** - Pre-production environment for testing.

**State Management** - Centralized data storage for application.

---

## T

**Token** - Authentication credential issued after login.

**TypeScript** - Superset of JavaScript with type safety.

---

## U

**Unit Testing** - Testing of individual functions.

**Use Case** - Specific project scenario with requirements.

---

## V

**Validation** - Process of checking data correctness.

**Vue.js** - Frontend JavaScript framework.

---

## W

**Webhook** - Automated callback for events.

**Worksheet** - Progress report submitted by students.

---

## X

**XSS** - Cross-Site Scripting. Security vulnerability.

---

## Y

**YAML** - Human-readable data format.

---

## Z

**ZIP** - File compression format.
