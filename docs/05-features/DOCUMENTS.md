# 📄 DOCUMENTS FEATURE

Centralized document repository for capstone project guidelines and resources.

---

## 📋 Overview

Document management allows:

- Upload capstone guidelines and resources
- Organize documents by category
- Search and filter documents
- Download documents
- Manage document access

---

## 📂 Document Categories

```
1. Guidelines
   - Capstone guidelines
   - Project requirements
   - Submission guidelines

2. Templates
   - Document templates
   - Report templates
   - Presentation templates

3. Examples
   - Sample projects
   - Example reports
   - Reference materials

4. Other
   - Miscellaneous documents
   - Additional resources
```

---

## 📤 Upload Document (Admin)

### Process

```
1. Go to "Kelola Dokumen"
2. Click "Upload Document"
3. Fill form:
   - Title: Document name
   - Category: Select category
   - Description: Optional details
   - File: Choose file
4. Click "Upload"
5. Document available to students
```

### File Requirements

```
- Maximum size: 50MB
- Allowed types: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, ZIP
- Virus scan: Automatic
```

---

## 🔍 View Documents (Student)

### Browse Documents

```
1. Click "Dokumen" in sidebar
2. See all available documents
3. Documents show:
   - Title
   - Category
   - Upload date
   - File size
```

### Search Documents

```
1. Go to Documents page
2. Use search box
3. Enter keyword
4. Results filter automatically
```

### Filter by Category

```
1. Go to Documents page
2. Click category filter
3. Select:
   - Guidelines
   - Templates
   - Examples
   - All
4. Documents filter
```

---

## 📥 Download Document

### Process

```
1. Go to Documents page
2. Find document
3. Click "Download" button
4. File downloads to computer
```

### Download Limits

- No download limits
- Unlimited access
- Can download multiple times

---

## 🗑️ Delete Document (Admin)

### Process

```
1. Go to "Kelola Dokumen"
2. Find document to delete
3. Click "Delete" button
4. Confirm deletion
5. Document removed from system
```

---

## 📊 Document Statistics

### Admin View

```
- Total documents: Count of all documents
- Documents by category: Breakdown
- Total downloads: Download count
- Storage used: Total file size
```

---

## 🔐 Access Control

- All students can view documents
- Only admins can upload/delete
- No login required for download (optional)

---

## ⚠️ Important Notes

- Documents are permanent (backup regularly)
- Large files may take time to upload
- Check file format before uploading
- Organize by category for easy access
