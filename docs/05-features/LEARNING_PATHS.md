# 🎓 LEARNING PATHS FEATURE

Learning path management and configuration.

---

## 📋 Overview

Learning paths define:

- Student specialization areas
- Team composition requirements
- DicodingId prefix
- Use case eligibility

---

```
1. Machine Learning
   - Code: ML
   - Prefix: ML
   - Description: Machine learning specialization

2. Front-End Web & Back-End with AI
   - Code: FEBE
   - Prefix: FEBE
   - Description: Full-stack web development

3. Mobile Development
   - Code: MOBILE
   - Prefix: MOBILE
   - Description: Mobile app development

4. Cloud Computing
   - Code: CLOUD
   - Prefix: CLOUD
   - Description: Cloud infrastructure
```

---

## 📊 View Learning Paths

### Student View

```
1. Go to Profile
2. See current learning path
3. Learning path cannot be changed by student
```

### Admin View

```
1. Click "Kelola Learning Path"
2. You'll see all learning paths
3. Each shows:
   - Name
   - Code
   - Description
   - Status (Active/Inactive)
   - DicodingId Prefix
```

---

## ➕ Create Learning Path (Admin)

### Process

```
1. Go to "Kelola Learning Path"
2. Click "Create Learning Path"
3. Fill form:
   - Name: Learning path name
   - Code: Unique code (e.g., ML)
   - Description: Details
   - Prefix: DicodingId prefix
   - Status: Active/Inactive
4. Click "Create"
```

---

## ✏️ Edit Learning Path (Admin)

### Process

```
1. Go to "Kelola Learning Path"
2. Find path to edit
3. Click "Edit"
4. Update information
5. Click "Save"
```

### What Can Be Changed

```
- Description
- Status (Active/Inactive)
- Prefix (use with caution)
```

### What Cannot Be Changed

```
- Name (after creation)
- Code (after creation)
```

## 🔐 Access Control

- Students assigned at registration
- Cannot be changed by student
- Admin can change (rare)
- Affects team composition rules

---

## ⚠️ Important Notes

- Learning path determines team composition
- Cannot change after registration
- Contact admin to change
- Affects DicodingId generation
