# 📅 TIMELINE FEATURE

Project timeline with milestones, deadlines, and event tracking.

---

## 📋 Overview

Timeline management allows:

- Create milestones and deadlines
- Track project progress
- Highlight upcoming deadlines
- Monitor overdue items
- View all events in calendar

---

## 📊 Timeline Types

```
1. Milestone
   - Major project checkpoint
   - Deliverable deadline
   - Phase completion

2. Deadline
   - Submission deadline
   - Registration deadline
   - Review deadline

3. Event
   - Workshop or seminar
   - Meeting or presentation
   - Important announcement
```

---

## 📈 Timeline Status

```
- Upcoming: Starts in future
- Ongoing: Currently happening
- Completed: Already finished
- Overdue: Passed deadline
```

---

## 📅 Create Timeline (Admin)

### Process

```
1. Go to "Kelola Timeline"
2. Click "Create Timeline"
3. Fill form:
   - Title: Event title
   - Description: Event details
   - Start Date: When it starts
   - End Date: When it ends
   - Type: Milestone/Deadline/Event
4. Click "Create"
5. Timeline visible to all students
```

---

## 🔍 View Timeline (Student)

### Browse Timeline

```
1. Click "Timeline" in sidebar
2. See all events
3. Events show:
   - Title
   - Description
   - Dates
   - Status (Upcoming/Ongoing/Completed/Overdue)
```

### Filter by Type

```
1. Go to Timeline page
2. Click type filter
3. Select:
   - Milestones
   - Deadlines
   - Events
   - All
4. Timeline filters
```

### Check Deadlines

```
1. Go to Timeline page
2. Look for status badges:
   - Red = Overdue
   - Yellow = Upcoming (within 7 days)
   - Green = Completed
3. Plan accordingly
```

---

## ✏️ Edit Timeline (Admin)

### Process

```
1. Go to "Kelola Timeline"
2. Find timeline to edit
3. Click "Edit" button
4. Update information
5. Click "Save"
6. Changes visible to students
```

---

## 🗑️ Delete Timeline (Admin)

### Process

```
1. Go to "Kelola Timeline"
2. Find timeline to delete
3. Click "Delete" button
4. Confirm deletion
5. Timeline removed
```

---

## 📊 Timeline Statistics

### Admin View

```
- Total events: Count of all events
- Upcoming events: Next 7 days
- Overdue events: Passed deadlines
- Completed events: Finished events
```

---

## 🔔 Notifications

- Upcoming deadline reminder (optional)
- Email notification 3 days before deadline
- Overdue notification

## ⚠️ Important Notes

- Check timeline regularly
- Mark calendar for important deadlines
- Plan work accordingly
- Contact admin if deadline unclear
