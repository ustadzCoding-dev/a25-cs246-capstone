# 📢 ANNOUNCEMENTS FEATURE

System-wide announcements for important updates and information.

---

## 📋 Overview

Announcement system allows:

- Create important announcements
- Set priority levels
- Reach all students
- Search announcements
- Track announcement history

---

## 🎯 Priority Levels

```
1. High Priority
   - Critical updates
   - Urgent deadlines
   - System maintenance

2. Medium Priority
   - Important information
   - Schedule changes
   - General updates

3. Low Priority
   - Optional information
   - Tips and tricks
   - General announcements
```

---

## 📤 Create Announcement (Admin)

### Process

```
1. Go to "Kelola Pengumuman"
2. Click "Create Announcement"
3. Fill form:
   - Title: Announcement title
   - Content: Announcement message
   - Priority: High/Medium/Low
4. Click "Publish"
5. Announcement visible to all students
```

### Best Practices

```
- Clear and concise title
- Detailed but readable content
- Set appropriate priority
- Proofread before publishing
```

---

## 🔍 View Announcements (Student)

### Browse Announcements

```
1. Click "Pengumuman" in sidebar
2. See all announcements
3. Announcements show:
   - Title
   - Content preview
   - Priority badge
   - Posted date
```

### Search Announcements

```
1. Go to Announcements page
2. Use search box
3. Enter keyword
4. Results filter automatically
```

### Filter by Priority

```
1. Go to Announcements page
2. Click priority filter
3. Select:
   - High
   - Medium
   - Low
   - All
4. Announcements filter
```

---

## ✏️ Edit Announcement (Admin)

### Process

```
1. Go to "Kelola Pengumuman"
2. Find announcement to edit
3. Click "Edit" button
4. Update content
5. Click "Save"
6. Changes visible to students
```

---

## 🗑️ Delete Announcement (Admin)

### Process

```
1. Go to "Kelola Pengumuman"
2. Find announcement to delete
3. Click "Delete" button
4. Confirm deletion
5. Announcement removed
```
