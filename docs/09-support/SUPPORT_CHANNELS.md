## 🐛 Reporting Issues

### Bug Report Template

**Title:** Brief description of bug

**Description:**

```
What I was doing:
- Step 1
- Step 2
- Step 3

What happened:
- Unexpected behavior

What should happen:
- Expected behavior

Error message:
- [Paste error]

Environment:
- OS: Windows/Mac/Linux
- Browser: Chrome/Firefox/Safari
- Node version: 18.x
```

### Feature Request Template

**Title:** Brief description of feature

**Description:**

```
Problem it solves:
- Current limitation

Proposed solution:
- How it should work

Alternative solutions:
- Other approaches

Additional context:
- Screenshots, examples
```

### Level 1: Self-Service

- Documentation
- FAQ
- Troubleshooting guide
- GitHub issues

### Level 2: Community

- Slack channel
- GitHub discussions
- Stack Overflow

### Level 3: Team Support

- Email support
- Office hours
- Direct contact

### Level 4: Escalation

- Critical issues
- Security concerns
- Production outages
